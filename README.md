# Sistema de Hábitos e Produtividade

Um aplicativo web moderno para acompanhar hábitos, gerenciar tarefas e aumentar sua produtividade no dia a dia.

![Preview](./assets/preview.png)

---

## Funcionalidades

- Criação e gerenciamento de hábitos
- Sistema de Streak (sequência de dias)
- Dashboard com progresso diário e semanal
- Calendário de contribuições (estilo GitHub)
- Lista de tarefas com prioridades
- Foco do Dia
- Pomodoro Timer integrado
- Gráficos de estatísticas
- Tema claro / escuro
- Dados salvos no navegador (LocalStorage)
- Totalmente responsivo

---

## Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (ES6+)
- Chart.js (gráficos)
- LocalStorage
